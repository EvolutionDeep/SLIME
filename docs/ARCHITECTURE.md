# SLIME Architecture

Three planes, two homes: on-chain state lives in the Anchor program; everything
observational and operational lives on Cloudflare Workers.

```
                    ┌───────────────────────────────┐
 Solana (devnet)    │  slime program (Anchor 0.30)  │
  Config/Agent/     │  genesis spawn tick_agent     │
  Strain/Proof      │  submit_result quarantine ... │
        ▲           └───────────────▲───────────────┘
        │ read (RPC)  /  write (signed txs)
        │                           │
┌───────┴───────────────────────────┴───────────────┐
│           Cloudflare Worker (worker/)             │
│  READ  /api/config /api/agents /api/strain/:root  │
│        /api/chronicle  /health                    │
│  WRITE cron */2 * * * *: tick_agent (bounded) +   │
│        advance_epoch   [VERIFIER_KEY secret]      │
│  ASSET dashboard (public/) — same origin, no CORS │
└───────────────────────────────────────────────────┘
```

## Why Cloudflare

- **Cron Triggers** replace the missing Solana-native timer: `tick_agent` and
  `advance_epoch` are heartbeat calls; the Worker is the murmur-style "cron +
  honest lastRun" pattern with hard safety valves (see below).
- **Static Assets binding** serves the dashboard from the same origin as the
  JSON API — one deploy, no CORS, KV/D1 not needed yet.
- **workerd cold starts** keep the idle cost at zero between cron fires.

## Safety valves carried from prior incidents

| Valve | Origin lesson | Effect |
|---|---|---|
| `MAX_TX_PER_RUN = 12` | murmur batch-starvation (2026-10-01) | one cron fire cannot monopolize the run |
| `RUN_DEADLINE_MS = 25s` | unbounded read sampling starving progression | whole-run wall-clock budget |
| `RPC_TIMEOUT_MS = 8s` per call | hung RPC masking liveness | every read races a timeout |
| no-`VERIFIER_KEY` = no-op cron | — | default deploys cannot spend or sign |
| breaker on-chain | murmur ECONOMY_REAL_SPEND | freezes spawning, chronicle keeps writing |

## Honest degradation

The dashboard always renders the simulation snapshot first
(`public/data/sim.json`, generated by `scripts/sim.mjs`). Live panels only
light up when `/health` reports `rpcOk` and `programDeployed`; banners state
exactly which layer is missing (blocked public RPC, undeployed program,
unset secret), never silently faking "live".

## Deploy sequence

1. WSL2: `anchor build`, regenerate program ID, update `lib.rs` + `Anchor.toml`
   + `worker/wrangler.toml`.
2. `anchor deploy --provider.cluster devnet` (validator config: devnet).
3. Initialize + genesis with `anchor keys`-managed authority.
4. `cd worker && npx wrangler deploy && npx wrangler secret put VERIFIER_KEY`.
5. Verify: `GET /health` → `rpcOk:true, programDeployed:true`;
   `GET /api/cron-run` → ticks advance; chronicle `seq` monotonic.
